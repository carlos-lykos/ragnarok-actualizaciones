# Ragnarök — canal de actualizaciones

Repositorio del canal de actualizaciones de Ragnarök 40K para Windows y Android.

- Las nuevas publicaciones de datos se distribuyen mediante GitHub Releases.
- Los clientes verifican una firma digital y las huellas SHA-256 antes de activar datos.
- Las listas personales se sincronizan de forma independiente mediante Dropbox.
- Este repositorio no debe contener claves privadas, contraseñas, perfiles ni tokens.

## Estado
La infraestructura está en preparación. Las pruebas técnicas no son actualizaciones del juego. Solo se publicarán datos cuya distribución esté autorizada.

La clave pública verifica las publicaciones; no permite firmarlas.
